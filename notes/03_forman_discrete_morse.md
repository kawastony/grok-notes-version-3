# Forman discrete Morse and relative depth

## Forman discrete Morse
Function on cells; discrete gradient pairs cells; critical cells unpaired; Morse complex recovers homology. No nontrivial closed gradient paths for a true Morse gradient.

## Forman–Ricci (graph)
Edge curvature from degrees and triangles (and weights in the general form). Negative ↔ branching; positive ↔ cliques.

## Mapping to the 3-bridge model

| Forman object | Model role |
|---------------|------------|
| Morse function / height | Identity ranking |
| Critical cells | Pause candidates (stall) |
| Forman–Ricci on mid edges | Local bridge curvature |
| R = F_mid - F_bar | Relative depth mediator |
| Discrete gradient flow | Single flow law; early ∂_t W = feed slope |
| New pairing under acceptance | Transfer map Φ |

Relative (not absolute) Forman depth is the operational R. Saucan et al. link Forman Morse, persistent homology, and Forman–Ricci — supporting curvature-defect tracking of critical structure.
