# Constitution v3 — Active / Pause phase pair

**Date:** 2026-09-29  
**Claim level:** Structural ontology inside the program (lattice, Forman, cone, SPARC tests). Not universal metaphysics yet.

## Primitives

| Term | Operational definition |
|------|------------------------|
| Active phase | Membership b fixed; state evolves under that bridge’s flow |
| Pause phase | Membership free or stuck; transfer map may reassign b |
| Bridge | One of {A, P_1, P_2} |
| Membership b | Discrete label of current geometry |
| Identity | Structural class setting relative depth |
| Relative depth R | F_mid - F_bar (or midpoint-support proxy) |
| Alignment α | Soft-channel acceptance score in [0,1] |

## Phase laws

### Law of Active Phase
On the active bridge, (v,I) evolve under locked geometry. Intensity expressed; membership fixed.

### Law of Pause Phase
On pause bridges, membership is free or stuck. v and I are continuous across the interval. Alignment can reattach membership. Resume continues from the same v with the same I under the new geometry.

### Conservation across pause
v⁺ = v⁻,  I⁺ = I⁻,  b⁺ ∈ B_adm(b⁻, R, α)

### Relative structure rule
Bridge occupancy and early feed rate are set by **relative** depth, not absolute curvature alone.

## Philosophical distinction from GR
GR: single standing geometric law; path and boundaries follow; no constitutive pause.  
This program: identity of the organizing bridge can be selected in pause; intensity is preserved; residual tests and index constrain admissible bridges.
